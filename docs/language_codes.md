# Поддерживаемые языки

`/translate` принимает двухбуквенные коды ISO 639-1:

| Код | Язык |
| --- | --- |
| `ru` | русский |
| `en` | английский |
| `de` | немецкий |
| `fr` | французский |
| `es` | испанский |
| `zh` | китайский |
| `ar` | арабский |

Для `source_lang` также разрешено значение `auto`; оно используется по
умолчанию. `target_lang=auto` запрещён. Коды нечувствительны к регистру и
нормализуются в нижний регистр.

Список описывает поддерживаемый контракт, а не подтверждённое качество модели.
В mock-режиме перевод и автоматическое определение языка не выполняются.
Перед включением реального провайдера каждую языковую пару нужно проверить на
сохранение смысла, имён, чисел, ссылок, разметки и нежелательного контента.

Поле языка пользователя в основном приложении: `preferred_language`.
